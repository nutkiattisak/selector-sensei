# Welcome to Selector Sensei

Master CSS Selectors comprehensively and become proficient in selecting elements with CSS.

## About This Course

Selector Sensei is a comprehensive learning resource covering all types of CSS Selectors, from basic to advanced levels, helping you write CSS efficiently and precisely.

## What You'll Learn

### 1. General Selectors
- Universal Selector - Select all elements
- Type Selector - Select by tag name
- Class Selector - Select by class
- ID Selector - Select by ID

### 2. Combinator Selectors
- Descendant Selector - Select descendants
- Child Selector - Select direct children
- Adjacent Sibling Selector - Select adjacent siblings
- General Sibling Selector - Select all siblings

### 3. Attribute Selectors
- Existence Attribute Selector - Check for existence
- Equality Attribute Selector - Check for exact value
- Prefix Attribute Selector - Check for prefix
- Suffix Attribute Selector - Check for suffix

### 4. Pseudo-class Selectors
- Dynamic Pseudo-classes - Dynamic interactions
- Structural Pseudo-classes - Document structure

### 5. Pseudo-element Selectors
- Pseudo-elements - Style specific parts of elements

## Getting Started

Begin with General Selectors to build a strong foundation, then gradually progress to more complex selectors.

Happy learning!
