# ยินดีต้อนรับสู่ Selector Sensei

เรียนรู้ CSS Selectors อย่างครบถ้วนและเชี่ยวชาญการเลือก Element ใน CSS

## เกี่ยวกับคอร์สนี้

Selector Sensei เป็นแหล่งเรียนรู้ที่ครอบคลุมทุกประเภทของ CSS Selectors ตั้งแต่พื้นฐานไปจนถึงระดับสูง เพื่อช่วยให้คุณเขียน CSS ได้อย่างมีประสิทธิภาพและแม่นยำ

## เนื้อหาที่คุณจะได้เรียนรู้

### 1. General Selectors (Selectors พื้นฐาน)
- Universal Selector - เลือกทุก Element
- Type Selector - เลือกตามชื่อแท็ก
- Class Selector - เลือกตาม Class
- ID Selector - เลือกตาม ID

### 2. Combinator Selectors (Selectors แบบผสม)
- Descendant Selector - เลือกลูกหลาน
- Child Selector - เลือกลูกโดยตรง
- Adjacent Sibling Selector - เลือกพี่น้องติดกัน
- General Sibling Selector - เลือกพี่น้องทั้งหมด

### 3. Attribute Selectors (Selectors ตามคุณลักษณะ)
- Existence Attribute Selector - ตรวจสอบการมีอยู่
- Equality Attribute Selector - ตรวจสอบค่าที่เท่ากัน
- Prefix Attribute Selector - ตรวจสอบคำนำหน้า
- Suffix Attribute Selector - ตรวจสอบคำต่อท้าย

### 4. Pseudo-class Selectors (Selectors แบบ Pseudo-class)
- Dynamic Pseudo-classes - การโต้ตอบแบบไดนามิก
- Structural Pseudo-classes - โครงสร้างเอกสาร

### 5. Pseudo-element Selectors (Selectors แบบ Pseudo-element)
- Pseudo-elements - จัดการส่วนเฉพาะของ Element

## เริ่มต้นการเรียนรู้

เริ่มต้นด้วย General Selectors เพื่อสร้างพื้นฐานที่แข็งแกร่ง จากนั้นค่อยๆ พัฒนาไปสู่ Selectors ที่ซับซ้อนมากขึ้น

สนุกกับการเรียนรู้!
