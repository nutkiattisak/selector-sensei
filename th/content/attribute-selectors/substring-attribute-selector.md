# Substring Attribute Selector

**Substring Attribute Selector** ใน CSS ([attribute*="value"]) ใช้เพื่อเลือก Element ที่มีค่าคุณลักษณะซึ่งมีสตริงย่อยที่กำหนดอยู่ในส่วนใดส่วนหนึ่งของค่า Selector นี้มีประโยชน์เมื่อคุณต้องการจัด Style ให้ Element ที่ค่าคุณลักษณะมีข้อความบางส่วนอยู่ ไม่ว่าจะอยู่ตำแหน่งใดก็ตาม

## ไวยากรณ์

```css
element[attribute*="value"] {
  /* CSS styles */
}
```

- `element` (ไม่บังคับ) ใช้เพื่อจำกัดการเลือกให้อยู่เฉพาะแท็ก HTML ที่กำหนด (เช่น `div`, `a` เป็นต้น)
- `attribute` คือชื่อของคุณลักษณะที่ต้องการตรวจสอบ
- `value` คือสตริงย่อยที่ต้องการค้นหาในค่าของคุณลักษณะ

## ตัวอย่าง

ตัวอย่างนี้จะเลือก Element `<a>` ทุกตัวที่มีคุณลักษณะ href ซึ่งมีคำว่า `"example"` อยู่ในส่วนใดส่วนหนึ่ง

```css
a[href*="example"] {
  color: orange;
}
```

## ตัวอย่างกับ Class

คุณสามารถเลือก Element ตามชื่อ class ที่มีคำเฉพาะอยู่ในชื่อ

```css
div[class*="card"] {
  border: 1px solid #ccc;
  border-radius: 8px;
}
```

ในกรณีนี้ จะจัดสไตล์ให้กับทุก Element `div` ที่ชื่อ class มีคำว่า `"card"` อยู่ เช่น `card-header`, `product-card`, `card-body` เป็นต้น

## ตัวอย่างกับรูปภาพ

ใช้เลือกรูปภาพที่มี URL มาจากแหล่งเฉพาะ

```css
img[src*="cdn.example"] {
  border: 2px solid blue;
}
```

จะจัดสไตล์ให้กับรูปภาพทุกรูปที่ `src` มีข้อความ `"cdn.example"` อยู่ในเส้นทาง

## การใช้งาน

- **URLs**: ใช้ Style ให้ลิงก์ที่มีโดเมนหรือเส้นทางเฉพาะอยู่ใน URL
- **Class names**: ใช้จัด Style Element ที่มีชื่อ class ที่มีคำร่วมกัน (เช่น `card`, `btn`, `nav`)
- **Data attributes**: ใช้เลือก Element ที่มี data attribute ซึ่งมีค่าเฉพาะอยู่ภายใน
- **Form elements**: ใช้เลือกฟิลด์อินพุตที่มีชื่อคุณลักษณะ `name` ซึ่งมีคำที่กำหนดอยู่

## ข้อสำคัญ

- Substring Attribute Selector มีความไวต่ออักษรตัวเล็กและตัวใหญ่
- จับคู่กับ Element ที่มีค่าคุณลักษณะ **มีสตริงย่อย** อยู่ในส่วนใดก็ได้ (ต้นค่า กลางค่า หรือท้ายค่า)
- สามารถใช้ร่วมกับตัวเลือกอื่นๆ เพื่อจัดสไตล์ที่เฉพาะเจาะจงมากขึ้น เช่น `a[href*="blog"]` หรือ `input[name*="email"]`

## เปรียบเทียบกับ Selector อื่นในกลุ่ม Attribute Selectors

| Selector | ไวยากรณ์ | การจับคู่ |
|---|---|---|
| Prefix | `[attr^="val"]` | ค่าเริ่มต้นด้วย `val` |
| Suffix | `[attr$="val"]` | ค่าลงท้ายด้วย `val` |
| **Substring** | `[attr*="val"]` | ค่ามี `val` อยู่ในส่วนใดก็ได้ |

## สรุป

Substring Attribute Selector เป็นเครื่องมือที่ยืดหยุ่นมากใน CSS ที่ใช้เลือก Element โดยอิงจากการมีสตริงย่อยอยู่ในค่าคุณลักษณะ มีประโยชน์โดยเฉพาะในการจับคู่รูปแบบที่อยู่ในส่วนใดก็ได้ของค่า ไม่จำกัดว่าต้องอยู่ต้นหรือท้ายเท่านั้น
